# Heart Island

Heart Island is a cozy 3D recovery companion. Complete gentle daily activities,
earn keepsakes, and decorate a living island with interactive 3D assets.

## Live website

- GitHub Pages: <https://cookie-tech117.github.io/aftergrow/>
- Project repository: <https://github.com/cookie-tech117/aftergrow>

## Features

- Interactive 3D island built with React Three Fiber
- Place, rotate, enlarge, and reduce island decorations
- Recovery activities and personalized onboarding
- Island progress, rewards, weather, motion, and particle effects
- Responsive iPhone-style presentation

## Local development

Node.js 22.13 or newer is required.

```bash
npm install
npm run dev
```

## GitHub Pages deployment

The workflow in `.github/workflows/deploy-pages.yml` builds and publishes the
static website after every push to `main`. In the repository settings, select
**GitHub Actions** as the GitHub Pages source.
